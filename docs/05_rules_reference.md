# 05 · 规则明细：29 类事件、档位、冷却与说话人护栏

> 以代码为准（决策框架原件是同事整理的、不公开，下文“挂哪条决策项”用的是我的转述，和 `coach/knowledge/decision_tree.md` 一致）：记录员 [`coach/events.py`](../coach/events.py)，编导的表 [`coach/playbook.py`](../coach/playbook.py)，编导的闸门 [`coach/director.py`](../coach/director.py)，说话人的护栏与校验 [`coach/speaker.py`](../coach/speaker.py)。事件类型的数目可以用 `python analysis/reproduce.py rules` 从源码静态数出来。

| 统计 | 数 |
|---|---|
| 事件类型 | **29 类**（跑毒按 来不及 / 偏紧 / 该规划 三档计 3 类），按决策树模块分 7 支 |
| 能说出口的动作 | 33 个：P0 3 个 / P1 12 个 / P2 14 个 / P3 7 个（有 3 个动作分两档） |

**没接的**：问“敌人在哪、这仗打不打得过”的两块一条都没接 —— 屏幕上读不出敌人在哪。**所有阈值是教练经验值，不是游戏规则**（6.3 米/秒、8% 掉血、50% 血线、弹匣 20%……）；想更安静或更啰嗦就调这些数，但“对不对”要真实玩家来校。

读表的方式：每支下面是“当……且…… → 判成一件事”（**记录员**的规则）；右边“档位 · 冷却 · 挂哪条决策项”是**编导**查的表。**连续帧确认**是记录员对抗单帧误读的主要手段：凡是标了“连续 N 行”的，单帧闪一下都不算。

## 安全区

**先算三个数**（人在圈外、离圈 ≥60 米时）：

- **需要多久**：步行 = 距离 ÷（6.3 米/秒 × 能量加成）；在车上、或离圈 ≥600 米该用车 = 距离 ÷ 18 米/秒（没在车上再加 15 秒找车）
- **还能用多久** = 缩圈倒计时 + 这一圈的圈外预算（第 1 圈 200 秒、第 2 圈 160 秒……越往后越短）× 当前信号值
- **比值** = 需要多久 ÷ 还能用多久

修正：正在缩圈且离圈 ≥150 米，“该规划了”升成“偏紧”；正在缩圈且信号 <75%，直接“来不及”；在车上且每秒接近 ≥5 米，降一档。**离圈 <60 米不出**：这个距离很可能是标记点的距离，不是圈距。圈距本身要**连续 2 行**都读到才认、取近 8 秒中位数。

| 事件 | 条件 | 档位 · 重提 / 冷却 · 决策项 |
|---|---|---|
| 圈外来不及 `ZONE_OUTSIDE_URGENT` | 比值 ≥ 1 | **P0 必须说** · 每 15 秒重提 · 冷却 45 秒 · 安全区在哪 / 转移路上会不会暴露（步行再挂“要不要开车转移”） |
| 圈外偏紧 `ZONE_OUTSIDE_TIGHT` | 比值 ≥ 0.6 | P1 · 每 25 秒 · 冷却 45 秒 · 什么时候缩圈 / 转移路上会不会暴露 |
| 该规划了 `ZONE_OUTSIDE_PLAN` | 离圈 ≥200 米，或倒计时 ≤60 秒 | P2 · 每 45 秒 · 冷却 90 秒 · 什么时候缩圈 / 下一个落脚点选哪 · 提示“不用催，手头的事收尾再走” |
| 正在掉信号 `SIGNAL_DROPPING` | 信号值比上一行掉 ≥1%（看下降，不看绝对值） | **P0 必须说** · 每 10 秒 · 冷却 20 秒 · 依据里带“还能扛约 N 秒” |
| 开始缩圈 `ZONE_SHRINK_START` | 倒计时变成 00:00，且人在圈内 | P3 · 冷却 240 秒 · 留给画面补：圈里的好点位 |
| 进圈了 `ZONE_ENTERED` | 之前在圈外，**连续 3 行**在圈内 | P3 · 冷却 90 秒 · 提示“一句肯定，别站圈心” |

安全区方位来自小地图：圈外时小地图上有一条白色虚线指向安全区，[`coach/minimap.py`](../coach/minimap.py) 在环带里找白像素的主方向；读不到就在提示里写“方位未知（不要说方向）”。

## 生命值

**“交战中”**：10 秒内掉过血或倒地，或 8 秒内开过火（同一把枪弹匣变少），或 8 秒内有自己的击杀横幅。**“正在打药”**：6 秒内出过用药横幅。**依据里直接给定性词**，不给裸数字：<30% 只剩一点 / <50% 掉了一半多 / <75% 不满 / <85% 差一点满。

| 事件 | 条件 | 档位 · 冷却 · 决策项 |
|---|---|---|
| 掉血 `SELF_HP_DROP` | 没倒地，两行之间血掉 ≥8% | 掉完 <50%：**P0 必须说**；否则 P1 · 冷却 12 秒 · 最近的掩体 / 继续打还是撤 / 被发现了要不要换位置 · 留给画面补：最近掩体的方向、受击方向标识 |
| 血低 `SELF_HP_LOW` | 血 <50%、没在打药、没倒地（每 20 秒重提） | 交战中 → P1 掩体后打药（只说用哪个药，掩体交给画面）；不在交战、有药 → P1 现在打药；没药 → P2 去找药 |
| 顶住一波 `SURVIVED_BURST` | 一下掉过 ≥30% 血，之后 20 秒没再掉、没倒 | P3 情绪 · 大约每场一次 · 留给画面补：点名他做对了什么 |
| 自己倒地 `SELF_DOWNED` | 队伍面板上自己那一行**连续 2 行**倒地（血条读 0 但面板没标倒地，不算） | P1 情绪 · 冷却 60 秒 · 安抚 + 先处理威胁还是等救 |
| 被扶起 `SELF_REVIVED` | 之前倒地，现在不再标倒地且血 >5% | P1 · 冷却 60 秒 · 先找掩体再打药 |
| 正在打药 / 喝能量 `HEAL_IN_PROGRESS` / `BOOST_IN_PROGRESS` | 出现用药横幅 | **不说话**；治疗话题压 20 秒（别在他打药的时候催他打药） |
| 趁空补能量 `ENERGY_TOPUP` | 能量 <61%、有能量药、血 70–86%、12 秒没掉血没开火、不在车上也不在圈外 | P3 · 每场最多一次 · 说“补满血”，不说“加速” |

选药规则（给说话人的提示）：圈外 → 补信号的药（止痛药、肾上腺素、饮料），圈外绷带急救包没用；血 ≥75% → 能量类；缺口 ≤25% → 绷带（4 秒）；血 <30% 且不在交战 → 医疗箱（8 秒）；否则急救包拉到 75%（6 秒）。

## 弹药

弹匣容量取本场见过的最大弹匣和这把枪的先验值里大的那个；读数先取近 3 行中位数，过滤掉不可能的值。

| 事件 | 条件 | 档位 · 冷却 · 决策项 |
|---|---|---|
| 弹匣快空 `AMMO_MAG_LOW` | 手上是枪，弹匣 ≤ max(3 发, 容量的 20%) **连续 3 行**（每 15 秒重提，换枪清零） | 交战中 P1（冷却 20 秒）/ 不在交战 P2（冷却 30 秒）· 现在能不能换弹 |
| 备弹不足 `AMMO_RESERVE_LOW` | 备弹 < min(弹匣容量, 40)，不在车上、不在交战（每 120 秒） | P2 · 冷却 150 秒 · 子弹够不够 / 还要不要接着搜 |

## 护具

| 事件 | 条件 | 档位 · 冷却 · 决策项 |
|---|---|---|
| 护具快烂 `GEAR_DAMAGED` | 头盔或护甲耐久 <30%，不在交战（每 90 秒） | P2 · 冷却 150 秒 · 头盔护甲还行吗 |
| 没护具 `GEAR_MISSING` | 开局 2 分钟后头盔或护甲还是 0，不在车上、不在交战（每 180 秒） | P2 · 冷却 240 秒 |

感知模型的护甲**等级**可信（1.000），**耐久百分比**不可信（四分之一的帧明显偏），所以规则只用“满 / 不满”这种粗粒度。

## 队友

**面板里有一行是玩家自己**，每场行号不同，事先标出来剔除；队友状态要**连续 2 行**才算数，离开列表 2 行才算这一段结束。

| 事件 | 条件 | 档位 · 冷却 · 决策项 |
|---|---|---|
| 队友倒地 `TEAMMATE_DOWNED` | 某队友连续 2 行倒地 | P1 · 冷却 25 秒 · 先清附近的威胁还是先扶人 / 怎么护住正在打药或扶人的队友 |
| 队友危险 `TEAMMATE_DANGER` | 某队友连续 2 行血条标红、没倒 | 自己血 <50% 或倒地：不说；自己在交战 P2、不在交战 P1（先顾自己）· 冷却 35 秒 · 画面里看不见他就不说方向 |
| 队友发消息 `TEAM_MSG` | 新出现一条队友消息 | 报敌情 P1（冷却 30 秒）；标记地点、喊集合 P2；要物资、空投这类不说 |

队友倒地的原因看前后 8 秒的横幅（被毒倒 / 自伤 / 被打倒）：被打倒且身上有烟 → 远处打才封烟、贴脸先处理眼前的人；被毒倒 → 直接扶，别浪费烟；你离得近又安全就你去，否则架枪、让最近的队友去；剩余 ≤8 人通常不扶。队友消息去重：同一个人、同一类消息 90 秒内只算一次，和 5 分钟内同类消息很像也丢（OCR 每帧抖字）；编号只认 1–4 且不是自己，否则只说“队友”。

## 战果与阶段

**剩余人数先平滑**：只收合理的读数（不少于队伍人数、不超过 100、比上次最多少 5 人），再取近 5 个的中位数。

| 事件 | 条件 | 档位 |
|---|---|---|
| 击倒 / 淘汰 `SELF_KNOCK` / `SELF_KILL` | 自己的击杀横幅（和上一条不同） | 淘汰：P3 夸一句；击倒：P3 夸一句 + P2 “开枪暴露了，该转点” |
| 队友拿人头 `TEAM_KILL` | 队友的击杀横幅 | P3 情绪 · 冷却 120 秒 |
| 人数跨档 `ALIVE_STAGE` | 剩余人数向下跨过 50 / 20 / 10 / 5 | ≤10 人：P2 稳住、防多个方向；身上有投掷物且 ≤15 人：P3 提醒用投掷物（每场一次） |
| 吃鸡 `MATCH_WON` | 对局结束时剩余人数 ≤ 队伍存活人数 | P1 情绪 · 带全场战绩 · **说完全场闭嘴**（后面是结算和回放画面） |

## 编导：说不说、先说哪件

```text
每一行读数进来：
如果 已经吃鸡 → 清空候选池，不再说话

① 入池：同一件事已经在池里 → 换成新的
② 过期：超过有效期 → 丢掉，记账
③ 逐条过闸：
   如果 刚看到打药横幅（治疗话题压 20 秒）或刚说完情绪句（情绪压 20 秒）→ 跳过
   如果 不是 P0 必须说，且 离同话题上一句不够久 → 跳过
        （安全区 30 秒、治疗 15、队友 20、载具 60、弹药 20、护具 60、生存 8 ……）
   如果 不是 P0 必须说，且 同意图上一句太近 → 跳过
        “进掩体”= 先找掩体 / 掩体后打药 / 开枪后转点 / 换弹，间隔 20 秒
        “打药”= 现在打药 / 掩体后打药，间隔 60 秒
        例外：“掩体后打药”被“进掩体”拦下 → 降级成“打药”，只留选药提示，再查打药间隔
   如果 同一件事还在冷却（冷却 × (1 + 0.5 × 已说次数)，最多 3 倍，P0 也不例外）→ 跳过
④ 打分 = 档位底分（P0 100 / P1 70 / P2 45 / P3 20）+ 紧急度（0–20）
        + 10（没说过或 2 分钟没说）/ −15（刚说过）
        − 类别均衡（P2/P3、说满 8 句后，某个子模块占比超过 25% 就扣分）
⑤ 合并：同话题留最高分，其余当成“同一件事的其它角度”带给说话人
   （同一步内再按意图跨话题合并一次 —— 这一步有个条件写错的 bug，从没触发过，见 04 §7）
⑥ 决定：
   如果 有 P0 必须说：
        正在说的也是 P0 → 等；否则 立刻说，正在说别的就打断
   否则 取最高分那件：
        P1 → 空闲 ≥2 秒 才说；否则排队，过了有效期也会丢
        P2 → 空闲 ≥6 秒，且没有 P0/P1 候选 → 说；否则排队，过期丢
        P3 → 正在说话 → 直接丢；空闲 ≥12 秒，且没有 P0/P1/P2 → 说
⑦ 说完：池里同话题的候选当作说过，删掉
```

离线回放里按一句 3.5 秒算“正在说话”；在线时应该换成真实语音时长，这一步还没接。

## 说话人：提示词里的禁令 + 生成后的代码校验

提示词里的禁令（管不严，所以后面还有代码校验）：

- 只输出那一句话，≤25 字；不要 JSON、引号、前缀
- 只说编导给的这一件事；画面只用来说得更具体，不许推翻决策、不许换话题
- 不复述血量百分比、圈距米数；正面表述优先；不和最近说过的话同一个开头
- 不自称队友（“等我扶”“我去”），只对玩家说“你”，队友的动作说“让 N 号……”
- **方向词只有两个来源**：安全区方位字段（只用来说进圈方向）；画面里看得见、并且点名了的东西
- 不说第几个圈、决赛圈、地名、敌人几米几楼，不预测圈往哪缩
- 识别可能有误：以画面为准，对不上就说得概括些；但不许因此换话题

| 校验 | 判不过的情况 |
|---|---|
| 方向词 `check_direction` | 方向词挂在队友、敌人、标记上（看不见）；或说圈的方向但当前不是安全区话题、方位未知；或去掉“方向 + 看得见的东西”后还剩光秃秃的方向词 |
| 冒充队友 `check_persona` | 出现“等我”“我去”“我扶”“我掩护”“我们上”这类话 |
| 照抄提示 `echoes_hint` | 整句 ≥8 字，而且原封不动是提示里的一段 |

判不过：把驳回原因加进提示词重生一次，三道校验重跑；还不过，就删掉方向短语，让模型照着改好的句子重新配音。**这三道校验目前只在离线整场回放里跑，真流式链路还没接上**（实跑第 15 句的问题就出在这里，见 [04 §6](04_coach_framework.md#6-真流式整场接上自己训的读仪表盘模型p1墙钟-30-分钟)）。
