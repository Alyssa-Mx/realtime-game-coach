# 教练用到的决策项（转述）

# 决策框架原件是同事整理的，不公开；这里只列规则实际挂上的那部分，名称是我的转述。
# 格式：模块 / 子模块 / 决策项。framework.py 加载时用它校验 playbook 里的每一条路由。

- 局势
  - 队友状况
    - 谁在打
    - 队友都在哪
  - 周边风险
    - 附近可能有人吗
  - 对局进程
    - 还剩多少人
- 资源与状态
  - 时机安不安全
    - 现在能不能打药
    - 现在能不能换弹
  - 自身状态
    - 血量
    - 子弹够不够
    - 头盔护甲还行吗
  - 物资够不够
    - 还要不要接着搜
- 走位
  - 毒圈
    - 安全区在哪
    - 什么时候缩圈
  - 怎么走
    - 转移路上会不会暴露
    - 借地形转移
  - 用车
    - 要不要开车转移
    - 车停哪
    - 车停这儿会不会暴露
    - 开车走哪条路
    - 这辆车还要不要开
  - 去哪
    - 下一个落脚点选哪
    - 圈里哪里好守
  - 找掩体
    - 最近的掩体
    - 会不会被看见
    - 这里会不会被多面夹击
  - 转点
    - 被发现了要不要换位置
    - 开枪后要不要挪位置
- 交战
  - 撤出与保命
    - 继续打还是撤
  - 信息共享
    - 队友报的信息要不要跟
    - 队友报没报敌情
  - 打法
    - 手上的枪合不合适这个距离
    - 打的时候怎么用掩体
    - 投掷物怎么用
  - 支援队友
    - 先清附近的威胁还是先扶人
    - 怎么护住正在打药或扶人的队友
    - 要不要过去帮打
  - 配合队友
    - 要不要等队友到齐再打
    - 要不要和队友拉交叉火力
  - 打还是不打
    - 打还是避
